Modèle de traduction du pack Europe de Chevaliers Translators (0.17.1 et suivantes), téléchargé par l'application. Il n'y a rien à installer à la main.

- MiLMMT-46 4B v1.0 (Xiaomi, entraîné à partir de Gemma 3) pour les langues européennes du projet ;
- vocabulaire limité aux écritures latine, grecque et cyrillique : le découpage d'un texte européen ne change pas ;
- quantifié en IQ4_XS avec une matrice d'importance calculée sur des traductions entre ces langues ;
- construit par GitHub Actions avec `outils/pack_europe.py` (workflow « Pack Europe ») ; l'empreinte SHA-256 est dans le fichier `.sha256`.
